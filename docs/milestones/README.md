# Milestones

Each milestone has a **plan** written before work starts (scope, deliverables, acceptance criteria, risks) and a **report** written at delivery (what was built, how it was verified, deviations, limitations, next steps).

| Milestone | Release | Plan | Report |
|---|---|---|---|
| M1 — Foundation & ingestion | v0.1.0 | [plan](m1-foundation/plan.md) | [report](m1-foundation/report.md) |
| M2 — Retrieval | v0.2.0 | [plan](m2-retrieval/plan.md) | [report](m2-retrieval/report.md) |
| M3 — Generation & API | v0.3.0 | [plan](m3-generation-api/plan.md) | [report](m3-generation-api/report.md) |
| M4 — Evaluation & hardening | v0.4.0 | [plan](m4-evals-hardening/plan.md) | [report](m4-evals-hardening/report.md) |

Release flow: feature branch → `dev` → `staging` → `main`, tagged at each milestone.
